## Mã nguồn cũ

Toàn bộ lịch sử và mã nguồn cũ (lõi UniKey/x-unikey, addon Fcitx5, engine,
tests, benchmarks, các nhánh feat/fix/test/perf/release...) được bảo toàn đầy đủ
trong nhánh `legacy` của repository này.

```bash
# Lấy mã nguồn cũ
git clone -b legacy <địa chỉ-repo-này>
# hoặc checkout nhánh legacy nếu đã clone:
git checkout legacy
```

Nhánh `legacy` là bản gộp (merge) của tất cả các nhánh phát triển cũ, được giữ lại
nhằm tham khảo và truy vết. Vui lòng KHÔNG tiếp tục phát triển trên nhánh
`legacy`; mọi đóng góp mới hãy gửi tại địa chỉ mới ở trên.
